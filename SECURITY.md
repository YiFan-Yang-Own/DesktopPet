# Security Policy

## Supported Versions

This project currently supports the latest source version on the default branch.

## Reporting a Vulnerability

Please open a GitHub issue with a clear description and reproduction steps. Avoid posting private data such as API keys, personal photos, or local database files.

## Local Data

DesktopPet stores learning records in:

```text
data/user_data.db
```

This file is ignored by Git and should not be published.
